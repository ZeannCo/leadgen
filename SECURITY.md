# Security and public scope

This repository is a curated portfolio edition. Production configuration, credentials, client datasets, internal identifiers, and original Git history are excluded. Example data is synthetic. The dashboard image in VM Tracker is a separately supplied, redacted screenshot of the original application.

Secret scanning and selected automated tests are release checks, not a security certification. Review authentication, network exposure, dependencies, authorization, and deployment configuration before using this code beyond a local demo. Do not add real scan exports, contact records, credentials, or generated reports to Git.

Report a suspected vulnerability privately through the contact information at https://zeann.dev. Do not put credentials or personal data in a public issue.
